${LABEL}: apt repository

Debian and Ubuntu packages, signed and served from GitHub Pages.

curl -fsSL ${BASE}/keys/repo.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/${ORIGIN}.gpg
sudo tee /etc/apt/sources.list.d/${ORIGIN}.sources >/dev/null <<'EOF'
Types: deb
URIs: ${BASE}/deb
Suites: stable
Components: main
Signed-By: /usr/share/keyrings/${ORIGIN}.gpg
EOF
sudo apt update
sudo apt install PACKAGE

This needs Debian 10 or Ubuntu 18.04 and newer. On Debian 9 or Ubuntu 16.04, install apt-transport-https first.
